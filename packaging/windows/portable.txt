MGRC-PDF portable mode

While this file sits next to selfpdf.exe, MGRC-PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the SelfPdfData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move MGRC-PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\MGRC-PDF and
%LOCALAPPDATA%\MGRC-PDF) instead. If SelfPdfData can't be written (for example on a read-only
drive), MGRC-PDF says so and uses the per-user folders instead.
